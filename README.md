## How "open to" is read

A location naming a country counts for that country only ("Remote - Poland" is PL). A location naming no country counts for a region it names ("Remote, EMEA") or for everyone when it says anywhere/worldwide/global. "Remote (US or Canada)" and bare "Remote" are left out. Check the posting: some employers add limits in the text.
